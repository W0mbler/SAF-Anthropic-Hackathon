## Summary

SAF Command is a geographic planning cockpit for sustainable aviation fuel infrastructure in Kalimantan. Using 80 biomass locations, 6,800 kt of available feedstock and four airports, a real SciPy/HiGHS mixed-integer model jointly selects depot and refinery sites, facility sizes and three-stage material flows. The interface makes capacities, costs, assumptions and solver gaps inspectable. Our free public demo offers three genuine solver-generated scenarios, an interactive atlas, comparisons, deterministic explanations and JSON/CSV exports. The complete Docker application adds editable assumptions, live Python optimisation, accounts and PostgreSQL history. The Pages demo presents build-time results rather than executing Python in the browser. Demand and conversion yield are illustrative; routes and sites require real-world validation. The project makes no verified emissions-savings or investment-return claims.
